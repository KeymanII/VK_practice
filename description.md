 Направление практики: Исследование степени феномена critical forgetting
 модели, дообученной на QLora 

 1. Введение

 1.1. Актуальность

Critical forgetting —  явление, которое описывается тем, что модель забывает general knowledge, полученный на основном датасете(более большом),
подстраиваясь под специфичные задачи(или стиль ответа) нового датасета. PEFT(и Lora в частности) призваны решить эту проблему благодаря тому,
что при использовании этой технологии изменению поддается не основная матрица весов модели, а добавочная(быть может, меньшей размерности)
. Данное исследование призвано выявить степень critical forgetting при дообучении с QLora, в частности легковесной.
Легковесные модели представляют интерес в связи с быстрым дообучением, инференсом, и легкостью переноса. Исследование позволяет увидеть,
насколько критично влияние critical forgetting на работу таких моделей, дообученных для выполнения специфических задач.


 1.2. Цель проекта

Цель: Дообучить визуально-языковую модель на основе открытых данных VK, замерить различие целевой метрики(rougeLsum),
на тестовом датасете до и после обучения.

 1.3. Задачи

1. Поиск датасета для дообучниея.
2. Выбор архитектуры. Выбор тестового датасета
3. Подготовка данных — объединение инструкций с изображениями, предобработка для обучения.
4. Измерение целевой метрики до дообучения
5. Дообучение модели — применение Parameter-Efficient Fine-Tuning (PEFT) с QLoRA.
5. Измерение целевой метрики после дообучения.
6. Анализ результатов.

 1.4. Ожидаемые результаты

- Дообученная VLM-модель.
- Воспроизводимый пайплайн эксперимента.
- Документация с описанием архитектуры, эксперимента и результатов
- Код для инференса и оценки модели

 2. Используемые данные

 2.1. GQA-ru

Источник: https://huggingface.co/datasets/deepvk/GQA-ru

GQA-ru — русскоязычная версия датасета GQA (Graph Question Answering), содержащая вопросы и ответы 
по изображениям из Scene Graph. Датасет состоит из двух частей:

- Инструкции (questions/answers):
  - `train_balanced_instructions` — ~72,000 пар "вопрос-ответ" на русском языке
  - `testdev_balanced_instructions` — ~12,000 пар для тестирования
  - Каждый пример содержит: `id`, `imageId`, `question`, `answer`, `fullAnswer`, метаданные

- Изображения:
  - `train_balanced_images` — изображения для обучения
  - `testdev_balanced_images` — изображения для тестирования
  - Формат: JPEG, RGB

Пример данных:
```json
{
  "question": "Кто в рубашке?",
  "answer": "парень",
  "fullAnswer": "Парень в рубашке",
  "imageId": "2395730"
}
```

 2.2. RuCommonVQA

(((Источник: https://huggingface.co/datasets/deepvk/MMBench-ru !!!

MMBench-ru — русскоязычная версия MMBench, бенчмарка для оценки мультимодальных моделей.

- Структура: Вопросы с вариантами ответов (multiple-choice, A/B/C/D)
- Разделы: dev-выборка для валидации

 3. Архитектура решения

 3.1. Базовая модель: LLaVA-gemma-2B-lora

В качестве базовой модели выбрана LLaVA-gemma-2B-lora, VLM от VK.

Обоснование:

1. Открытая.
2. Легкий инференс, понятная структура промпта.
3. Леговесная.

 3.2. Метод дообучения: QLoRA

Для эффективного дообучения используется QLoRA (????????? Low-Rank Adaptation), описание: !!!

- Замораживает исходные веса модели
- Добавляет обучаемые низкоранговые матрицы к слоям внимания
- Требует на порядок меньше памяти, чем полное дообучение
- Позволяет быстро адаптировать модель под конкретную задачу

Параметры LoRA: !!!
- Rank (r): 16
- Alpha: 32
- Target modules: Q, K, V, O проекции + Gate, Up, Down проекции


 3.3. Технологический стек
